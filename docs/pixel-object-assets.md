# Pixel object assets

Final flat, lower-resolution sprite revisions generated with the built-in image-generation tool. Transparent PNG deliverables: `public/objects/cartridge.png`, `public/objects/journal.png`, `public/objects/cassette.png`, and `public/objects/communicator.png`.

Original generated art remains in the generation library. The user requested replacement with flat, front-facing, coarse 2D sprites. Only objects use pixel rendering; project screenshots, typography, and SVG light ribbons remain smooth. CSS does not add dimensional drop shadows to the sprites.

## Final prompts

### cartridge.png

Redraw the reference object as a genuinely low-resolution FLAT TWO-DIMENSIONAL 8-bit game inventory sprite. Subject: a front-facing square game cartridge with two small corner notches, a simple violet label with one four-point star, and four connector marks along the bottom. Target a 24-by-24 to 32-by-32 logical pixel grid, enlarged with nearest-neighbor into a transparent square image. Each individual pixel must be a BIG clearly visible hard square; only about 24-32 pixels across the object, not hundreds. Strictly front elevation, no perspective, no isometric angle, no visible depth or side planes. Extremely simple, charming old NES-era pixel art, maximum 6 solid colors: dark navy outline, cobalt blue, light blue, violet, pale lavender, cream. One-pixel-thick logical dark outline. Minimal flat color blocking. NO gradients, NO shiny edges, NO beveling, NO smooth shading, NO volumetric lighting, NO texture, NO rendered 3D, NO tiny details, NO shadows or glow. Center the complete isolated object at 70% canvas size with consistent transparent padding. No lettering, no surrounding decorations. Genuine transparent alpha background. The reference only identifies the object and palette; replace its detailed dimensional rendering completely.
